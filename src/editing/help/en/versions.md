# Versions and their numbers

Numbers are given by the platform, never typed.

- An accepted version is numbered **N.M**: N canonical editions before it, M acceptances since the last one.
- Work waiting for review is numbered from the last accepted version: **2.3-1** is the first version after 2.3. Before anything is accepted the base is 0.0, so a new document's first version is **0.0-1**.
- A canonical edition is **N.0**.
