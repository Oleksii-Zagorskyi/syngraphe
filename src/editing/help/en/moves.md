# How a document moves

A document is written, reviewed, approved and kept.

1. **Editing.** Someone with the right to edit opens the *Edit* tab. While they edit, the document is *held*: nobody else can edit it, and what they type is kept as a draft only they see.
2. **Sending for review.** *Finish editing* shows the changes and a summary. *Send for review* makes a version of them, which waits in the document's pending edits.
3. **Review.** A reviewer reads the pending edits and accepts them, corrects them, or returns them with a reason.
4. **Approval.** A document can be frozen and its latest accepted version made canonical: the next edition, the one the organisation stands behind.

Nothing is lost on the way: every version stays in the document's history.
