          What the editor accepts

          Text is written in Markdown, in the editor's rich view or its source view. These constructs are accepted; anything else is refused when it is pasted, with its line named and, where one exists, a conversion offered.

          ConstructHow it is written
          Headings, four levels# Heading to #### Heading
          Paragraphsseparated by an empty line
          Lists, three levels deep- item, 1. item
          Bold, italic**bold**, *italic*
          Underline[text]{.underline}
          Entities — role, action, term[text]{.role #id}, .action, .term
          Quotes> text
          Callouts — note, warning, example> [!note] on a line of its own
          Tables, not inside another block| a | b |
          Images of the document, on a line of their own![description](images/name.png)
          Links[text](https://…), mailto:, a path in the document
          Not accepted, and what the conversion does
          ConstructConverted to
          a heading below depth foura heading of depth four
          a code block, inline codeits text
          HTMLits text, the tags removed
          a horizontal ruleremoved
          a footnoteits text in brackets where it was referred to
          a table inside a list, quote or calloutthe table after the block that held it
          an image from outside the documentleft out, with a notice
          …every other construct, one fixed way each

          The limits, the entities, the callout types and every refusal with its conversion are read from the platform's specification of the allowed Markdown, the one the editor and the server read.
