# Enhancement proposals and the roadmap

An **enhancement proposal** (`EP-NNNN`) describes one initiative too large for a backlog row: the problem, its goals and non-goals, first principles, the approach, what is still unresolved, and the facts that move it forward. It is the counterpart of an ADR one level up — an ADR records a decision, a proposal records an initiative and the decisions it will need.

**Status:** provisional → accepted → implementable → implemented, or deferred, withdrawn, rejected, superseded. A proposal is never deleted or moved; once implemented, it stays as the record of why the initiative happened, and the current behaviour lives in the product documents and the ADRs it links to.

**Horizon** places a proposal on the roadmap below.
